# Настройка Unsplash

1. Откройте [Unsplash Developers](https://unsplash.com/developers), войдите в аккаунт и создайте приложение в разделе Your applications.
2. В настройках приложения найдите **Access Key**. Secret Key для чтения List Photos не нужен.
3. В корне репозитория скопируйте шаблон, если локального файла ещё нет:

   ```sh
   cp -n Docs/Secrets.example.plist GalleryApp/Secrets.plist
   ```

4. Откройте `GalleryApp/Secrets.plist` в Xcode и замените `YOUR_ACCESS_KEY` значением Access Key у строки `unsplashAccessKey`.
5. Пересоберите и запустите приложение: ⌘R. После изменения ключа нужна новая сборка.

В новом клоне репозитория локального файла нет: создайте его из шаблона по шагу 3.
Ключ не нужно присылать в чат или вставлять в исходники. `Secrets.plist` исключён из Git на любом уровне.
В Xcode файл автоматически входит в синхронизированную папку GalleryApp и копируется в приложение.
Без него проект тоже собирается, а приложение показывает сообщение о настройке.

Перед коммитом можно проверить:

```sh
git check-ignore GalleryApp/Secrets.plist
git ls-files GalleryApp/Secrets.plist
```

Первая команда должна вывести путь, вторая — ничего.

## Допущение для тестового задания

Локальный plist защищает ключ от попадания в Git, но ключ можно извлечь из собранного
приложения. Для публичного распространения потребуется серверный прокси: секреты
должны оставаться на сервере. В этом учебном этапе используется прямой URLSession-запрос.

## Проверка с настоящим ключом

1. Запустите приложение с интернетом: должна загрузиться первая страница (30 фото).
2. Прокрутите к концу: следующая страница добавляется к существующим фотографиям.
3. Отключите интернет перед следующей страницей: уже загруженные фото остаются,
   появляется сообщение и кнопка «Повторить». Включите интернет и повторите запрос.
4. Потяните сетку вниз: первая страница загружается заново.
5. Быстро прокрутите вниз и обратно: старые ответы не должны подменять фото переиспользованной ячейки.
6. Нажмите подпись автора под фото: откроется профиль автора Unsplash.

Demo-приложения Unsplash имеют ограничение запросов; при исчерпании лимита приложение
показывает отдельное сообщение. Автоматических бесконечных повторов нет.

Источники: [List Photos и авторизация](https://unsplash.com/documentation),
[требования к использованию API](https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines).
