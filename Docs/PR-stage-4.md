# Просмотр фотографий внутри приложения

Нажатие на фотографию в сетке теперь открывает отдельный экран через AppCoordinator.
Раньше выбор фото был отключён, доступна была только внешняя ссылка автора.

- Большое изображение из regular URL, описание с запасным текстом, индикатор и повтор загрузки.
- Горизонтальное перелистывание загруженного списка через UIPageViewController, счётчик и возврат в галерею.
- PhotoDetailsViewModel хранит выбранный индекс и проверяет границы; отменённый свайп не меняет выбор.
- Ссылка автора остаётся отдельным действием. Разметка выполнена кодом через Auto Layout.
- README обновлён; добавлена Docs/Architecture-walkthrough.md с объяснениями для защиты.

Проверено: сборка Xcode, 12 тестов Swift Testing, SwiftLint 0.65.1 (0 замечаний), git diff --check.
На симуляторе iPhone 17 проверены открытие второй фотографии внутри приложения, свайпы 2 → 3 → 2,
поворот в landscape, прокрутка длинного описания, возврат в галерею и обратно в portrait.
Перекрытий и падений не обнаружено; сессия проверки завершена.
В diff нет настроенного API-ключа, Secrets.plist не отслеживается Git.

Допущение: просмотр использует снимок списка на момент открытия; пагинация выполняется в галерее.
Избранное и сердечки относятся к следующему этапу.
