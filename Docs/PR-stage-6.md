# Финальные тесты и документация GalleryApp

README подготовлен для нового читателя: запуск, ключ, архитектура, избранное,
допущения, реальные скриншоты и проверка приложения. Добавлены сценарий демонстрации
и вопросы для защиты, результаты проверки требований и список нужных снимков.

Пустые тесты шаблона заменены проверкой описания и переходов между вкладками.
Добавлены проверки отмены запроса, некорректного JSON, HTTP 401 и конца пагинации
при пустом ответе с Link next. Всего 22 unit-теста Swift Testing и 1 UI-тест.

Проверки: сборка Xcode успешна, все 23 теста прошли, SwiftLint без новых замечаний,
git diff --check без ошибок. На iPhone 17 проверены повороты с вкладками, просмотр,
синхронизация сердечек и удаление; получены 6 настоящих скриншотов.
Настроенный ключ не найден в истории Git, локальный Secrets.plist и личные настройки Xcode не включены.

Ограничения проверки явно указаны в Docs/Verification.md: нет прогона на iOS 17/iPad,
измерений Instruments и полного ручного офлайн-сценария. Изображения в Core Data
не сохраняются; просмотр использует снимок уже загруженного списка.

PR подготовлен для просмотра пользователем; автоматического объединения нет.
