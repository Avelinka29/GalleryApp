# Unsplash: загрузка, пагинация и кеш изображений

Ветка: `feature/unsplash-api` → `main`.

Галерея получает фотографии из Unsplash List Photos по 30 на страницу. При прокрутке
следующая страница добавляется к текущему списку. Ошибки не удаляют загруженные фото;
повтор запрашивает неуспешную страницу. Без ключа отображается инструкция настройки.

## Изменения

- Photo и вложенные модели Decodable, включая необязательное описание и данные автора.
- UnsplashPhotoService: URLSession/async-await, проверка HTTP-кода, обработка лимита запросов.
- GalleryViewModel: защита от параллельных запросов, удаление дубликатов по id,
  повтор страницы, pull-to-refresh и завершение пагинации.
- ImageLoader: NSCache, URLCache, общие загрузки одинаковых URL и асинхронная подготовка миниатюр.
- PhotoCell: отмена старой задачи и проверка id, загрузка/ошибка/повтор изображения,
  ссылка на автора Unsplash. Layout вынесен в GalleryLayout.
- Экран начальной загрузки, пустого ответа и ошибки; ошибки следующей страницы показываются под сеткой.
- Ключ читается из игнорируемого GalleryApp/Secrets.plist. В Git только безопасный шаблон.
- README и инструкция получения/настройки ключа обновлены.

## Проверено

- BuildProject с тестовыми target: успешно.
- Swift Testing: 9 тестов успешно. Проверены повтор страницы, параллельная загрузка,
  обновление, дубликаты, пустой ответ, отсутствие описания, HTTP-параметры и авторизация,
  rate limit, отсутствие ключа, объединение загрузок и кеш изображений.
- SwiftLint: без новых нарушений; 5 старых замечаний AppDelegate остаются в baseline.
- iPhone 17 / iOS 27.2: запуск без ключа, повтор, portrait/landscape, отсутствие падений и предупреждений Auto Layout.
- Secrets.plist входит в локальный app bundle, но отсутствует в отслеживаемых файлах Git.

## Что проверить с реальным ключом

Действующий Access Key в рабочую копию не добавлен. Успешная загрузка живой ленты,
прокрутка сетки с сетевыми изображениями и реальный HTTP-кеш в UI пока не проверены.
Тесты сервиса используют URLProtocol и не обращаются к Unsplash.

После [настройки ключа](https://github.com/Avelinka29/GalleryApp/blob/feature/unsplash-api/Docs/Unsplash-setup.md) запустить приложение, проверить первую и
следующую страницы, отключение/восстановление сети, pull-to-refresh и быструю прокрутку.

Локальный plist защищает ключ от попадания в Git, но не от извлечения из приложения.
Для публичного распространения нужен серверный прокси; текущий вариант — для тестового задания.
Список фото пока не сохраняется между запусками. Просмотр и избранное — следующие этапы.
PR не объединяется автоматически.
