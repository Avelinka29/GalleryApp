# Проверка перед сдачей

Дата: 8 ноября 2026. Схема GalleryApp, симулятор iPhone 17 / iOS 27.2.
Минимальная версия target — iOS 17.0; включены iPhone и iPad, portrait и landscape.
Фактический запуск на iOS 17 и полный прогон на iPad в этой среде не выполнялись.

## Соответствие заданию

- Swift и UIKit: весь интерфейс написан на UIKit, разметка — Auto Layout кодом.
- MVVM + Coordinator: состояние и загрузка во ViewModel, создание экранов и переходы в AppCoordinator.
- Сеть: URLSession и async/await, List Photos, per_page=30.
- Галерея: UICollectionView, отдельная PhotoCell, пагинация без параллельных запросов страницы.
- Изображения: NSCache и URLCache, объединение загрузок одного URL, проверка id и отмены при переиспользовании ячейки.
- Просмотр: regular-изображение, описание с запасным текстом, свайпы по загруженному списку, сердечко.
- Избранное: вкладка, удаление, единое состояние, Core Data / SQLite между запусками.
- Состояния: загрузка, пустой список, ошибки сети/изображений/избранного, повтор.
- Проверки: SwiftLint и тесты ViewModel с подменными сервисами; SQLite-тест использует временную базу.
- Документация: README, настройка Access Key, архитектура, допущения, скриншоты и сценарий защиты.
- Git: feature-ветки и PR; Secrets.plist исключён, .xcodeproj отслеживается.

## Ручная проверка перед демонстрацией

1. Запустить через ⌘R с собственным ключом, проверить загрузку и прокрутку нескольких страниц.
2. Открыть фото, перелистнуть, повернуть устройство, прочитать длинное описание и вернуться.
3. Добавить фото, перейти в избранное, перезапустить и проверить сохранение.
4. Удалить фото из просмотра и из списка; сверить сердечки в галерее.
5. Отключить сеть перед загрузкой новой страницы; восстановить сеть и нажать «Повторить».
6. Проверить повтор загрузки отдельного изображения, если его нет в кеше.
7. На собственном iPhone проверить обе ориентации и быструю прокрутку.

Ошибки сети проверены автоматически с подменными ответами. Полный офлайн-сценарий
и все размеры устройств вручную не проверялись. Измерения FPS, памяти и производительности
через Instruments не выполнялись; отсутствие видимых рывков не является результатом профилирования.
