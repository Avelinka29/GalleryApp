# Избранное на Core Data и синхронизация экранов

Добавлены вкладки галереи и избранного. Сердечко в ячейке или просмотре сохраняет фото
локально; повторное нажатие удаляет его. Изменение обновляется на всех экранах после успешной записи.

- FavouritesRepository хранит метаданные в Core Data / SQLite, без копирования изображений в базу.
- FavouritesStore предоставляет единое состояние, защищает от одновременных записей,
  уведомляет ViewModel и сохраняет прежнее состояние при ошибке записи.
- FavouritesViewModel и GalleryViewModel используют общий интерфейс PhotoGridViewModel
  для одного экрана коллекции; переходы остаются в AppCoordinator.
- Добавлены загрузка, пустое состояние, ошибки и повтор неудавшейся операции.
- README и памятка для защиты объясняют Core Data, синхронизацию и ограничения.

Проверка: сборка Xcode; 17 содержательных тестов Swift Testing, в том числе новый SQLite-файл,
повторное открытие, дубликаты, удаление, синхронизация ViewModel, ошибки чтения/записи и повторные нажатия.
SwiftLint проверяет код без новых замечаний; git diff --check без ошибок.

На симуляторе iPhone 17 проверены: пустое состояние, добавление из галереи, сердечко
в просмотре, удаление из просмотра и списка, синхронизация вкладок, сохранение после
перезапуска процесса без удаления приложения. Тестовое избранное удалено после проверки.
Поворот экрана с новыми вкладками в этой сессии не проверялся.

Допущения: схема Core Data задана кодом (id, addedAt, JSON payload). Для поиска по отдельным
полям понадобится расширение схемы. Изображения доступны через HTTP-кеш и сеть;
сохранение метаданных не гарантирует офлайн-загрузку картинок. Избранное не меняет лайки Unsplash.
Просмотр сохраняет снимок списка при удалении, чтобы свайпы не меняли индексы неожиданно.

PR объединяет пользователь. Следующий этап — финальная проверка и материалы для сдачи.
